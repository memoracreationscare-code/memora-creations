🔐 Admin security: 2-step login

Dekh raha hu...

Chalu karne par admin login me password ke baad aapke phone ke Authenticator app (Google / Microsoft Authenticator) ka 6 digit code bhi lagega. Koi aapka password jaan bhi le to bina phone ke andar nahi aa sakta.

  1. Phone me Google Authenticator (ya Microsoft Authenticator) kholein, + dabayein.
  2. Ye QR scan karein (ya "key" khud type karein).
  3. App me dikh raha 6 digit code neeche daalein.
